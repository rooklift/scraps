Hold down a combination of keys. If a key you are pressing doesn't light up, it is being blocked. If a key you are not pressing lights up, that is ghosting.

Windows quirks: Alt Gr also sends a fake left Ctrl. With Num Lock on, Shift + a numpad key makes Windows send a fake Shift release. Print Screen only sends a release, so it never shows as held, just as pressed. The Win key and things like Ctrl+W / Alt+Tab can't be captured unless you use the fullscreen + keyboard lock button (Chromium-based browsers only; hold Esc to leave).
